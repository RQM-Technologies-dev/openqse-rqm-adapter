# Historical OpenQSE working-group material

This directory preserves documents from when this GitHub repository hosted
OpenQSE Compiler Working Group notes.

Those notes are **not** the purpose of this repository anymore.

The RQM OpenQSE Adapter is an RQM-owned implementation prototype. It does not
define OpenQSE, govern the working group, or claim official OpenQSE status.

Keep this folder for history. Do not treat its charter as the adapter
specification.
